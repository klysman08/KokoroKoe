Opacity is currently one window's setting rather than a per-window matrix; independence becomes meaningful when the insights window exists. Compact mode changes spacing and text size only and does not resize the window. The translucent rendering has not been visually confirmed on a real desktop from this environment: the transparent window and the background-only opacity layer are verified by contract and unit tests, and a human check of readability at the opacity floor over varied backgrounds is still required, which is also the readable-text half of the R-010 gate. Quick-hide, shortcuts, monitor preference, geometry persistence, and click-through remain unimplemented.
